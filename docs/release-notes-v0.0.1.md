# StudyBoard v0.0.1

首个公开发布版：一个**本地优先、双击即用**的学习看板。

## ✨ 亮点

- **独立窗口**：用 Edge 应用模式（`--app`）打开，没有地址栏，像是原生小应用——不需要 Electron
- **零黑框启动**：VBS 启动器自动检测端口 → 起服务 → 开窗口；已运行时不重复开启（单实例）
- **数据全在本地**：`plan.json` 一个文件就是全部数据；每天自动快照备份（保留 14 份）
- **一键导出周报**：页面右上「🖊导出留档」→ 下载 Markdown，便于备份、迁移或贴进周报
- **三层分离**：数据（`plan.json`）/ 逻辑（`server.js`）/ 视图（`dashboard.html`），改功能只需加字段 + 加渲染

## 📦 功能

- 周计划打卡（周一~周日，任务可自定义，周日复盘不计入进度）
- 月度小项目追踪（步骤 + 进度条）
- 临时任务清单
- 连续打卡天数（由打卡日期自动计算）
- 保命规则 / 最近记录
- 周报导出（Markdown）

## 🚀 快速开始

1. 装 [Node.js](https://nodejs.org/)（≥ 18）
2. 双击 `启动看板.vbs` —— 首次运行会自动从 `plan.example.json` 生成你的 `plan.json`
3. 停止：双击 `停止看板.bat`

> 服务只监听 `127.0.0.1:3099`，不对外网开放。

## 📁 文件结构

| 文件 | 作用 |
|---|---|
| `server.js` | 零依赖本地 HTTP 服务，读写 `plan.json` |
| `dashboard.html` | 页面：卡片渲染 + 导出逻辑 |
| `plan.json` | 唯一数据源（已在 `.gitignore` 中） |
| `plan.example.json` | 示例数据，首次运行自动复制 |
| `启动看板.vbs` | 无黑框启动器（端口检测 + 单实例） |
| `停止看板.bat` | 按端口找到进程并停止 |
| `docs/screenshot.png` | 界面截图 |

## ⚠️ 已知限制

- 仅支持 Windows（启动器是 VBS/BAT；核心 `server.js` 跨平台可手动运行）
- 服务需常驻后台；关掉启动器窗口 = 看板停止
- 数据存单个 JSON 文件，并发写入未做锁（单人使用场景无影响）
